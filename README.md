# الجوهرة نت 2 — Jawhrah2

بوابة Hotspot عربية مخصصة لراوتر MikroTik RouterOS v6، مبنية من ملفات HTML/CSS/JavaScript محلية دون مكتبات JavaScript خارجية.

## التثبيت

1. احتفظ بنسخة احتياطية من مجلد `hotspot` الحالي في الراوتر.
2. ارفع ملفات الجذر (`index.html` و`login.html` و`status.html` وغيرها) ومجلدي `css` و`js` و`font` إلى مجلد ملفات الهوتسبوت النشط بالهيكل نفسه.
3. تحقق من إعدادات المصادقة الفعلية للـ Hotspot وUser Manager/RADIUS قبل النشر. آلية إرسال كلمة المرور الحالية تفترض نمط دخول يقبل كلمة المرور العادية (HTTP PAP أو مسارا متوافقا في إعدادات الراوتر). لا تعتبرها دعما مؤكدا لـ HTTP CHAP فقط.
4. اختبر الدخول بكرت صحيح وخاطئ ومنتهي وعلى جهاز آخر، ثم الخروج وإعادة الدخول، وتحقق من الاستجابة على هاتف قديم وحديث.
5. لا ترفع المشروع إلى استضافة ويب عامة وتتوقع تشغيل متغيرات `$(...)`؛ هذه المتغيرات يفسرها RouterOS فقط.

## الوظائف المحفوظة

- تسجيل دخول باسم المستخدم وكلمة المرور، وإظهار/إخفاء كلمة المرور.
- آخر كرتين (مع كلمات المرور) محليا لمدة 30 يوما، ومسح السجل. **لا تستخدم الحفظ على جهاز مشترك.**
- حالات الرصيد والوقت، تسجيل الخروج، وتصنيف رسائل الراوتر المعروفة بالعربية.
- الأسعار ونقاط البيع والتعليمات والدعم، والوضعان الليلي والنهاري والثيمات الأربعة.
- شعار الجوهرة المتحرك في مركز الحلقات، مع أداء أخف على الأجهزة الضعيفة.

## التحقق

- `node --check js/portal.core.js`
- `node tests/test_diagnostics.js`
- `python -m unittest discover -s tests -v` (بعد تثبيت `beautifulsoup4` و`tinycss2`؛ الاختبارات البصرية اختيارية)
- اختبارات المتصفح: `RUN_BROWSER_TESTS=1 python -m unittest discover -s tests -v` على بيئة بها Playwright + Chromium ويمكنها فتح `localhost`.
