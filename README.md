# الجوهرة نت 2 — Jawhrah2

مشروع ملفات بوابة Hotspot للمايكروتيك RouterOS v6. هذه صفحة دخول محلية، وليست موقع استضافة عام. راجع ملف التقرير وملفات البوابة في مجلد الجذر بعد دمج فرع التحسينات.

**تنبيه:** نجاح اختبارات الشيفرة لا يغني عن اختبار الدخول والخروج على راوتر MikroTik فعلي، وخصوصا ضبط `login-by` وRADIUS/User Manager.
